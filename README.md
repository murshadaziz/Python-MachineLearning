# Python-MachineLearning

A personal sandbox for learning and experimenting with machine learning in Python. This repository collects my projects and practice code across different ML libraries and frameworks, including PyTorch, TensorFlow, NumPy, Matplotlib, and more as I explore them. Each project lives in its own folder with its own README, so you can jump straight into whichever one interests you. Expect a mix of neural network implementations, data handling, and visualization experiments as the collection grows.
